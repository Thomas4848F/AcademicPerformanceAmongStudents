# 📊 Анализ успеваемости студентов: Влияние подготовительных курсов и социально-демографических факторов

[![Pandas](https://img.shields.io/badge/Pandas-2.2.0-blue.svg)](https://pandas.pydata.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Аналитическое исследование, направленное на выявление ключевых факторов, влияющих на академическую успеваемость студентов. Проект включает полный цикл анализа: от проверки статистических гипотез до формирования actionable-рекомендаций для образовательных учреждений.

---

## 🎯 Бизнес-контекст и цель

**Проблема:** Образовательные учреждения стремятся повысить успеваемость студентов, но ресурсы (подготовительные курсы, менторские программы, стипендии) ограничены. Необходимо понять, какие факторы действительно влияют на результаты экзаменов и для каких групп студентов поддержка будет наиболее эффективной.

**Цель:** Провести статистически обоснованный анализ данных, чтобы:
- Оценить эффективность подготовительных курсов
- Выявить влияние социально-демографических факторов
- Обнаружить эффекты взаимодействия между различными факторами
- Сформировать data-driven рекомендации для распределения ресурсов

---

## 📋 Проверенные гипотезы

**H1:** Прохождение подготовительного курса статистически значимо увеличивает средний балл на экзаменах.  
**H2:** Уровень образования родителей влияет на академические результаты студентов.  
**H3:** Существует эффект взаимодействия между социальным статусом студента и эффективностью подготовительных курсов.

---

## 🛠 Методология анализа

Проект использует строгий статистический подход с учетом характера распределения данных:

### 1. Описательная статистика (EDA)
- Анализ распределений баллов по предметам (math, reading, writing)
- Выявление выбросов и проверка нормальности распределения
- Сегментация данных по ключевым факторам

### 2. Проверка гипотез
**A/B тестирование:** Сравнение двух групп (с курсом vs. без курса)
**Статистические тесты:**
- t-критерий Стьюдента (для нормально распределенных данных)
- U-критерий Манна-Уитни (непараметрический аналог для ненормальных распределений)
- **Дисперсионный анализ:** Критерий Крускала-Уоллиса для сравнения 3+ групп
- **Post-hoc анализ:** Тест Данна с поправкой Бонферрони для корректного множественного сравнения

### 3. Визуализация
- Сравнительные бар-чарты с аннотациями
- Распределения баллов по группам
- Анализ эффектов взаимодействия

## 📈 Ключевые инсайты

### 1. Эффективность подготовительных курсов
- Студенты, завершившие подготовительный курс (completed), показывают совокупный средний балл 72.7, тогда как студенты без подготовки (none) — 65.0.
- **Итог:** Курсы дают прирост +7.6 пунктов (~11.7%). Разница статистически значима (p-value < 0.05).

### 2. Влияние образования родителей
- Наблюдается прямая корреляция: студенты из семей, где родители имеют степень магистра (master's degree), показывают результаты в среднем на 5-8 пунктов выше, чем студенты из семей с уровнем образования some high school или high school.

### 3. Эффект взаимодействия (Interaction Effect)
- Подготовительные курсы оказывают непропорционально высокое влияние на социально уязвимые группы (например, студенты со статусом free/reduced lunch). Для них прохождение курса компенсирует недостаток ресурсов и дает больший относительный прирост баллов, чем для студентов из обеспеченных семей (standard lunch).

## 💡 Практические рекомендации

На основе статистического анализа сформированы следующие data-driven рекомендации для администрации учебных заведений:

### 1. Таргетирование ресурсов: В первую очередь направлять на бесплатные подготовительные курсы студентов с льготным питанием (free/reduced). Это обеспечит максимальный ROI (возврат инвестиций) в виде роста общей успеваемости.

### 2. Программа менторства: Внедрить дополнительный академический саппорт для студентов, чьи родители имеют низкий уровень образования, так как этот фактор сильно коррелирует с результатами экзаменов.

### 3. Комплексный подход: Сочетать академическую подготовку с социальной поддержкой, так как анализ показал синергию этих факторов.

## 📚 Методологические заметки

### 1. Выбор статистических тестов:
- Перед применением параметрических тестов (t-тест, ANOVA) была проведена проверка на нормальность распределения. В ряде подгрупп распределение отличалось от нормального, поэтому для надежности выводов использовались непараметрические аналоги: U-критерий Манна-Уитни и Критерий Крускала-Уоллиса.

### 2. Проблема множественных сравнений:
- При сравнении более чем двух групп (например, 5 уровней образования родителей) возрастает риск ошибки первого рода (ложноположительного срабатывания). Для решения этой проблемы применялся Post-hoc тест Данна с поправкой Бонферрони, которая корректирует уровень значимости (alpha) для каждого отдельного сравнения.
