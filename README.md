# 📊 Анализ успеваемости студентов

## 🎯 Цель проекта
Проверить гипотезы о влиянии различных факторов на академические результаты студентов.

## 📋 Проверенные гипотезы
1. Влияние подготовительного курса на результаты экзаменов
2. Влияние уровня образования родителей на успеваемость
3. Взаимодействие социального статуса и эффективности курсов

## 🛠 Используемые методы
- Описательная статистика
- A/B тестирование (t-тест, U-критерий Манна-Уитни)
- Дисперсионный анализ (Крускала-Уоллиса)
- Post-hoc тест (Данна с поправкой Бонферрони)

##  Ключевые выводы
- Подготовительные курсы увеличивают средний балл на X пунктов
- Студенты из семей с высоким уровнем образования показывают лучшие результаты
- Курсы особенно эффективны для социально уязвимых групп (interaction effect)

## 💡 Практические рекомендации
1. Приоритетное предоставление курсов студентам с льготным питанием
2. Программа менторства для студентов из семей с уровнем образования high school
3. Комплексная поддержка: курсы + питание + консультирование
